I’m a Software Engineer based in Auckland, New Zealand. For the past 10+ years I’ve built and scaled high-concurrency distributed systems at ByteDance (TikTok) and Baidu, mainly focused on backend infrastructure, microservices, Linux performance tuning, storage systems and low-level networking (TCP/IP, RDMA).

I also work across the stack. I like modern frontend tooling like React and Node.js, and I’d rather build something end to end than just own the backend half of it. Lately I’ve been using agents in my own workflow, and I’m still figuring out how far that actually changes what a small team can ship. This blog is where I write about my thoughts, experience and understanding of the industry, as well as some daily life things.

More importantly, I am developing and leading information systems for some local organizations, and I’ve learnt a lot of local business knowledge and culture.

What I work with

  • Languages & backend: Golang, C++, Node.js, TypeScript, PHP (Laravel/HHVM), Shell
  • Cloud & infrastructure: AWS (EC2, RDS, DynamoDB, SNS, SQS, Lambda), Docker, Kubernetes, Ansible
  • Distributed systems & middleware: Kafka, RabbitMQ, Elasticsearch, Etcd, Istio
  • Data management: MySQL, PostgreSQL, Redis, MongoDB
  • Systems & networking: Linux performance tuning, TCP/IP and RDMA optimization
  • Frontend: React, Vite, Tailwind CSS
  • DevOps & observability: GitHub Actions CI/CD, Prometheus, Grafana, ELK, IaC

Experience

ByteDance (TikTok), Senior Software Development Engineer

Oct 2018 to Feb 2026, Beijing

Object Storage Team (TOS)

  • Cut global storage overhead by 30% by implementing erasure coding, lowering hardware costs while improving data durability
  • Re-architected metadata storage from MySQL to a distributed LSM-Tree KV store, resolving small-file explosion bottlenecks and stabilizing the system under traffic spikes
  • Built a multi-dimensional traffic control system (QPS/bandwidth throttling) for resource isolation and cascading-failure prevention in multi-tenant environments

Distributed File System Team (ByteStore)

  • Raised system QPS from 1,000 to 3,000+ and cut latency by 30% through Raft consensus and metadata caching optimizations
  • Designed a sharding scheme that scaled metadata capacity from 10M to 100M+ files using Bloom filters for sub-second retrieval
  • Improved availability to 99.99% by optimizing leader election and automated recovery, cutting MTTR from 30s to under 5s

Network Programming Team (ByteRPC)

  • Built a latency-critical RPC framework running on 200,000+ physical machines, improving network throughput by 50-400% across the storage ecosystem
  • Integrated RDMA and DPDK to bypass kernel bottlenecks, cutting 4K RTT latency from 12μs to 7μs
  • Built a high-performance C++ coroutine library and lock-free shared-memory IPC, reducing inter-process communication latency to under 1μs

Baidu, Software Engineer

Jul 2015 to Oct 2018, Beijing

  • Guaranteed 100% transaction accuracy across millions of daily payments using distributed locking and idempotency mechanisms
  • Architected high-availability systems with PHP (Laravel), Go, and Kafka to absorb 10x traffic spikes during major promotions while keeping sub-100ms response times
  • Built a real-time MySQL-to-Elasticsearch data pipeline, cutting transaction search latency from seconds to under 200ms for fraud detection
  • Developed a full-stack ops platform (React, Node.js, MongoDB) with self-service querying and RBAC, cutting manual data requests by 70%
